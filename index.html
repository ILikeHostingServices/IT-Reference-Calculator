PoE Budget And UPS Runtime

      

        
PoE Budget

        

        
Use the power each device actually draws if you know it; the class value is the worst case the switch reserves.

        

        
        

        

      

      

        
UPS Runtime (Estimate)

        

        

        

        

        

        
Battery Wh is volts x amp-hours x battery count (for example 2 x 12 V 9 Ah = 216 Wh). Add the PoE total above to the load if the switch is on this UPS.

        

        

        
A planning estimate. The UPS maker's runtime chart is the authority, and batteries lose capacity with age and heat.
