Free IT Calculators and References

Tools for networks, DNS and email, storage, and infrastructure, plus everyday admin helpers. Everything runs in your browser and keeps working offline; only DNS Lookup and Email Security send the name you look up to a public DNS resolver. Press Ctrl K or / to search.

Subnet Planner

Carve an IPv4 block into subnets sized for each VLAN or site, summarize routes, or split an IPv6 prefix into site and VLAN networks.

Plan Subnets (VLSM)

One line per subnet: a name and how many devices it needs to hold.

Summarize Routes

Paste networks (one per line or comma separated) to find the fewest routes that cover exactly them, and the single smallest supernet.

Split an IPv6 Prefix

Splitting on a multiple of 4 bits (for example /48 into /52, /56, or /64) keeps each subnet on a clean hex digit. The subnet ID is the hex value that goes in those bits, so subnet ID 2a of a /48 split into /64s is 2001:db8:abcd:2a::/64.

PoE Budget and UPS Runtime

      

        
PoE Budget

        

        
Use the power each device actually draws if you know it; the class value is the worst case the switch reserves.

        

        
        

        

      

      

        
UPS Runtime (Estimate)

        

        

        

        

        

        
Battery Wh is volts x amp-hours x battery count (for example 2 x 12 V 9 Ah = 216 Wh). Add the PoE total above to the load if the switch is on this UPS.

        

        

        
A planning estimate. The UPS maker's runtime chart is the authority, and batteries lose capacity with age and heat.

      

    


    

      
Power, Heat, and Circuit Load

      

        
Use the measured draw (UPS or PDU readout) when you have it; nameplate ratings are worst case.

        

        

        

        

        

        
The 80% rule (US NEC) limits a continuous load to 80% of the breaker rating. Check local code and the PDU's own rating, and keep each circuit of an A/B pair under 40% so either can carry the whole load.
